# 项目概况（00-profile）

- 本项目使用 Godot 4.7.2 进行开发。
- 本项目旨在1:1复刻游戏《吸血鬼幸存者（Vampire Survivor）》的功能，以完整解锁全部功能的状态为准，基础功能无需随着关卡推进逐步解锁，而是一开始就全部解锁。（实际上全部完成会比较困难，所以由我来决定砍掉哪些部分）
- 视觉风格采用《吸血鬼幸存者》原作的 2D 像素风格，即俯视角 2D 管线；**不采用 HD2D**（曾评估过，现已砍掉，评估资料已归档到 `Docs-Archived/01-hd2d-style.md`，仅作留档，不代表项目方向）。
- 视觉方向定为 2D 后，景深、体积雾、泛光等专为 3D 混合渲染服务的特性不在范围内；现有 GL Compatibility 渲染方式满足需求，无需切换 Forward+。

---

## 保留系统范围

地图只做一关，参考吸血鬼幸存者的第一关“疯狂森林”。
系统保留：开始、收藏、邪魔图鉴、小地图、超武合成配方、秘法牌、计时二倍速（关卡选择界面“倍速”选项）、移速二倍速（关卡选择界面“血战”选项）。
